Warehouse management without the complexity

Warehouse OS gives your team one place to manage inventory, products, locations and the full receive-pick-ship workflow. Three roles, a live dashboard, and barcodes on every product, all running on your own infrastructure.

Everything a warehouse team needs

Purpose-built modules replace spreadsheets and scattered tools with a single, auditable system of record.

Role-based access

ADMIN, MANAGER and PICKER permissions are enforced on both the API and the interface. Pickers only complete orders assigned to them.

Inventory you can trust

Live stock per product and bin, reserved units kept separate, guarded adjustments and an immutable movement history for every change.

Products with barcodes

Every product gets a unique Code 128 barcode automatically. Upload product images, download barcode SVGs and print labels.

Receive, pick, ship

Create inbound orders, receive partial quantities, assign picks and ship with over-receive and double-ship protection built in.

Operations dashboard

Clickable KPIs with drill-downs, stock-value and units-by-location charts, an operational flow diagram and an activity timeline.

Light and dark themes

A complete dark interface with a full light theme. The preference persists, and charts adapt their text colors automatically.

Run it in minutes

Node.js 20 or newer is all you need for the local SQLite setup.

git clone https://github.com/azzazy967/warehouse-os.git
cd warehouse-os
npm run setup
npm run dev:sqlite

Open http://localhost:5173 and sign in with one of the local demo accounts described in the README. Full setup and production deployment guides are in the repository.
